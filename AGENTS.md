# Working rules

Keep the seed and both vendor packages synthetic. Do not let the repair agent modify either vendor directory, tests or unrelated documentation. Validate a dependency change from a separate fresh `npm ci --offline` install; a passing test in an old `node_modules` directory does not prove lockfile consistency.

The grader stays outside the agent checkout. Do not call scripted tests live Codex proof. Add Firedrill integration only against the verified new release.

Keep original baseline commit/tree outside the agent checkout and require it for scope. Never replace it with current HEAD; include ignored/committed/type/alias/mode changes. Materialize only a coherent validated source and reject altered package scripts/metadata before execution. Fresh validation uses offline npm-ci and unchanged public tests/external grader, rechecking source between commands. Do not let SDK completion or prose override failed compatibility/scope.

Decoded SDK events are not raw provider/CLI proof. Keep SDK-inserted cache-write zero distinct from unknown original measurement, preserve failure/partial edits and stop work on recording faults. Runtime config/key/home is owned per call; caller SDK injection remains caller-owned. Owned relay/async commands now qualify original CLI capture and observed separate job groups in82 checks, including actual bundled loopback tool upgrade/cancellation and stalled-relay fallback. Preserve host ancestry, root/job freeze before signals, separate defunct/group facts and unknown inventory failure; never signal inherited application groups or trust model/namespace PIDs. Keep malicious escape/unobserved rapid daemonization outside containment claims; caller SDK/factory resources are separate and unknown drain fails. Paid model behavior remains a parked gate; bundled ordinary tool lifecycle is independently qualified offline. Complete #26 backport, then #27 data/archive in PLAN.md. Preserve historical live evidence as historical; do not refresh paid runs without its parked gate.

Preserve prepared executable/prompt/source/command evidence before dispatch, original CLI bytes/JSONL and separate SDK normalization/usage/errors, bounded private files and confirmed group/relay exit. SDK return and visible shell grouping alone cannot prove independently detached job cleanup. Qualify the actual bundled tool runtime through a controlled public loopback provider where possible; never invent responses/tool schemas or pay for a model to bypass the parked gate. Keep fs/recording waits and caller injection scope distinct from hard wall/heap/wire/billing guarantees.
